Start fresh

Throws away every entry held on this phone and starts it empty. The setup stays, so you do not have to paste the token again. Meant for clearing practice entries before the real logging starts — not for tidying up a wrong entry, which is what Fix and × on each row are for.

It does not clear the repo. Entries already pushed stay there until they are removed separately, and this phone will pull back anything the other phone still holds.

Nothing is ever deleted here. Undo marks an entry deleted and keeps it, the way the archive does.

Entries are kept in this browser and pushed to data/events/<date>/<device>.jsonl. A Claude Code session compacts those into data/raw/<date>.jsonl when you ask it to.

Without a token the app still works and keeps everything locally — it just does not push. Nothing is lost; it syncs once a token is set.
